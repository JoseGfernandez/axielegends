# 🎮 Axie Legends - Motor 3D

Motor gráfico para juegos 3D en navegador basado en **Three.js**.

---

## ✨ Características

- 🎥 **Cámara isométrica a 60°** - Vista estratégica del campo de batalla
- 🐱 **Minions con forma de gato bípedo** - Melee (espada) y Mage (bastón mágico)
- ⚔️ **Sistema de oleadas** - Nueva oleada cada 15 segundos
- 🗿 **Estatuas de Axie como torres** - Con báculo y gema brillante
- ⚡ **Rendimiento optimizado** - Sin sombras para mayor fluidez
- 🎯 **Movimiento por click** - El Axie se mueve haciendo click en el suelo
- 📊 **FPS Counter** - Monitor de rendimiento en tiempo real
- 🩸 **Barras de vida** - Actualización instantánea al recibir daño

---

## 🎮 Controles

| Acción | Tecla |
|--------|-------|
| **Mover al Axie** | Click izquierdo en el suelo |
| **Reiniciar posición** | `R` |

---

## 🛠️ Instalación

```bash
# 1. Clonar el repositorio
git clone https://github.com/JoseGfernandez/axielegends.git

# 2. Entrar a la carpeta
cd axielegends

# 3. Instalar dependencias
npm install

# 4. Iniciar el servidor de desarrollo
npm run dev
